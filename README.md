# DICOM Camera website

Commercial product website for DICOM Camera, intended for `https://dicom.camera`. Built as a fully prerendered static site: React 18 + TypeScript + Vite 5, Tailwind CSS 3 with shadcn-style primitives (Radix UI), GSAP 3 (ScrollTrigger, ScrollSmoother, SplitText, ScrollTo), Three.js + React Three Fiber + drei for two procedural brand accents, lucide-react icons and sonner toasts.

Routing is hash-based (owner decision): every page is served from the single `index.html` and addressed as `https://dicom.camera/#/workflows/`, `…/#/support/` and so on. The homepage markup is prerendered at build time (fast first paint, crawlable home), and the client renders the other pages from the same bundle. Legacy path URLs such as `/workflows/` are shipped as tiny redirect stubs that forward to the matching hash route, so old links keep working on any static host.

## Requirements

- Node.js 20 or newer (built and verified with Node 22)
- npm 10 (a `package-lock.json` is committed; use `npm ci` for reproducible installs)
- Nothing outside this folder: the original store artwork and its provenance manifests are in `assets-source/` (never modified, never deployed); the image build step writes optimised derivatives into `public/images/`

## Commands

```bash
npm ci                    # install exact dependencies from the lockfile
npm run dev               # Vite dev server (client-rendered, hot reload) at http://localhost:5173
npm run images            # rebuild optimised image derivatives from assets-source/ (also runs inside build)
npm run build             # images → client build → SSR build → prerender to dist/ (preview: noindex)
npm run build:production  # same, with VITE_INDEXABLE=true (index,follow + permissive robots.txt)
npm run preview           # serve dist/ at http://localhost:4173
npm run typecheck         # TypeScript
npm run lint:content      # content boundary checks against dist/ (forbidden terms, h1 count, metadata)
npm run verify            # Playwright: screenshots at 360/390/768/1024/1440 + landscape, axe scans, links, keyboard flows
```

`npm run build` output:

```
dist/
  index.html                       prerendered homepage; serves every hash route (/#/workflows/, /#/support/, …)
  workflows/index.html …           redirect stubs: /workflows/ → /#/workflows/ (one per route, noindex)
  404.html                         redirect stub → /#/404/ (the not-found page)
  sitemap.xml  robots.txt  site.webmanifest  favicon.ico  icon-*.png  apple-touch-icon.png  social-card.jpg
  assets/      hashed JS/CSS/fonts (three.js and GSAP are separate lazy chunks)
  images/      responsive AVIF/WebP/PNG screenshot derivatives and icon sizes
  badges/      official App Store (SVG) and Google Play (PNG) artwork, unchanged
verification/prerendered/          private full server renders of every route, used by `npm run lint:content`
```

Routes: `/#/` (home), `/#/workflows/`, `/#/enterprise/`, `/#/integration/`, `/#/privacy-and-retention/`, `/#/download/`, `/#/support/`, `/#/contact/`; any other hash path shows the not-found page.

## Project layout

```
src/config/site.ts         canonical origin, store URLs, email routes, legal links, indexing and motion switches
src/content/*.ts           all page copy as typed objects (see CONTENT-EDITING.md)
src/pages/*.tsx            one component per route, each exporting `meta` (title, description, path)
src/routes.tsx             route registry used by the client router and the prerenderer
src/components/            reusable pieces: header, footer, badges, screenshot figures/gallery, diagrams, FAQ, email action, contact form
src/components/three/      procedural WebGL scenes (deferred, client-only, aria-hidden)
src/components/MotionProvider.tsx, src/lib/motion.ts   GSAP layer
src/images/manifest.ts     GENERATED by scripts/build-images.mjs — do not edit
scripts/build-images.mjs   crops and responsive derivatives from assets-source/ (records DERIVATIVES.json)
scripts/prerender.mjs      prerendered home, redirect stubs, 404.html, sitemap.xml, robots.txt, private per-route renders
scripts/check-content.mjs  content boundary checks
scripts/verify.mjs         browser verification (Playwright + axe)
```
